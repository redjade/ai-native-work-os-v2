# 사전 준비

정규 수업은 설치 시간이 아니라 프로젝트 제작에 사용합니다. 첫 수업 전에 아래 항목을 확인합니다.

## 1. 장비 확인

- [ ] 본인이 사용할 노트북을 준비했다.
- [ ] 운영체제 업데이트를 완료했다.
- [ ] 충전기와 마우스 등 필요한 장비를 준비했다.
- [ ] 저장공간이 최소 10GB 이상 남아 있다.
- [ ] 브라우저에서 이메일을 확인할 수 있다.
- [ ] 파일과 폴더를 만들고 이름을 변경할 수 있다.
- [ ] 수업 장소의 Wi-Fi에 연결할 수 있다.

공용 PC나 학교 관리 PC는 프로그램 설치가 제한될 수 있습니다. 이 경우 첫 수업 전에 강사에게 알려야 합니다.

**새 노트북을 살 필요는 대개 없습니다.** 이 과정의 AI는 클라우드에서 계산되므로 고성능 장비나 그래픽카드가 필요하지 않습니다. 지금 가진 장비로 되는지, 태블릿·크롬북은 어떤지, 휴대폰·원격 작업에 무엇이 필요한지는 [내 장비로 되는지 확인하기](01e-hardware-check.md)를 참고합니다.

## 2. 계정 확인

- [ ] 개인 이메일 계정
- [ ] GitHub 계정
- [ ] 수업에서 사용할 AI 계정 1개
- [ ] 이메일 또는 인증 앱을 이용한 로그인 가능 여부
- [ ] 미성년자인 경우 필요한 보호자 동의

계정 비밀번호, 복구 코드, API 키는 강사에게 보내지 않습니다.

## 3. 도구 설치

수업에서는 강사가 지정하거나 참가자와 합의한 코딩 에이전트 하나만 사용합니다.

- [ ] [Git](https://git-scm.com/downloads)
- [ ] [Obsidian](https://obsidian.md/download)
- [ ] [Codex](https://developers.openai.com/codex/quickstart) 또는 [Claude Code](https://docs.anthropic.com/en/docs/claude-code/getting-started) 중 하나
- [ ] 텍스트 또는 코드 편집기

여러 도구를 한꺼번에 설치하지 않습니다. 운영체제와 계정 종류에 따라 설치 방법이 다르므로 공식 설치 문서를 우선 사용합니다.

설치 순서:

1. [도구 선택 안내](01a-tool-choice.md)에서 주 도구를 정합니다.
2. [macOS 설치 안내](01b-setup-macos.md) 또는 [Windows 설치 안내](01c-setup-windows.md)를 따릅니다.
3. [Obsidian 볼트 만들기와 모바일 연동](01d-setup-obsidian.md)으로 노트 작업공간을 만들고 휴대폰에서도 확인할 수 있게 준비합니다.
4. 두 도구를 모두 설치하더라도 첫 프로젝트는 주 도구 하나로 진행합니다.

터미널 명령이 어렵게 느껴져도 괜찮습니다. 이 과정은 변경 확인·커밋을 **화면(GitHub Desktop, 에이전트 앱의 Git 화면)으로 하는 것을 기본**으로 합니다. 터미널은 익숙해지고 싶은 사람을 위한 선택입니다.

## 4. 작동 확인

Git이 제대로 설치됐는지만 확인합니다. 두 방법 중 편한 쪽을 씁니다.

- **화면으로**: GitHub Desktop을 설치·실행해 로그인되면 Git이 함께 준비된 것입니다.
- **터미널로**: 아래 명령을 실행해 버전이 보이면 됩니다. 명령이 익숙하지 않다면 환경 점검 시간에 강사와 함께 진행합니다.

```text
git --version
```

선택한 에이전트가 설치되었다면 해당 도구의 버전 확인 명령도 실행합니다.

- [ ] Git 버전이 표시된다(또는 GitHub Desktop이 실행된다).
- [ ] Obsidian이 실행된다.
- [ ] GitHub에 로그인할 수 있다.
- [ ] 선택한 AI 도구에 로그인할 수 있다.
- [ ] 테스트 폴더 안의 텍스트 파일을 AI가 읽을 수 있다.
- [ ] AI가 만든 변경사항을 적용하기 전에 확인할 수 있다.

## 5. 작업 폴더 만들기

개인 작업공간은 다음처럼 시작합니다.

```text
ai-workspace/
  HOME.md
  projects/
  knowledge/
  templates/
```

경로에는 가능하면 짧은 영문 이름과 하이픈을 사용합니다. 클라우드 동기화 폴더와 Git을 함께 사용할 때 충돌이 발생할 수 있으므로, 처음에는 로컬 폴더 하나를 기준으로 사용합니다.

## 6. 정보 분류

프로젝트에 사용할 자료를 먼저 분류합니다.

| 등급 | 예시 | 수업에서의 처리 |
|---|---|---|
| 공개 가능 | 직접 만든 공개 글, 공개 데이터 | 사용 가능 |
| 개인용 | 개인 일정, 비공개 초안 | 필요한 부분만 사용 |
| 제한 정보 | 학교 자료, 연구 원자료, 타인의 문서 | 허가와 이용 조건 확인 전 사용 금지 |
| 비밀정보 | 비밀번호, API 키, 주민번호, 주소 | 입력·저장·업로드 금지 |

## 7. 프로젝트 후보 준비

첫 수업 전 아래 문장을 작성합니다.

```text
나는 __________________ 문제를 겪고 있다.
이 문제를 해결하기 위해 __________________ 결과물을 만들고 싶다.
4주 뒤에는 __________________ 상태이면 완료로 판단한다.
```

프로젝트 후보를 두 개 준비하고, 수업에서 더 작고 검증하기 쉬운 것을 선택합니다.

## 8. 사전 자기진단

각 항목에 0~3점을 적습니다.

- 문제를 작은 작업으로 나눌 수 있다: __점
- AI에게 맥락과 완료 조건을 설명할 수 있다: __점
- AI 결과를 직접 확인할 방법을 안다: __점
- 파일 변경 이력을 남기고 복구할 수 있다: __점
- 다른 사람이 따라 할 설명서를 쓸 수 있다: __점
- 개인정보와 비밀정보를 구분할 수 있다: __점

점수는 경쟁이나 선발에 사용하지 않습니다. 4주 뒤의 변화를 확인하기 위한 기준점입니다.

## 첫 수업 전에 강사에게 알릴 내용

- 설치되지 않은 도구
- 로그인 또는 결제 문제
- 관리 권한이 없는 노트북
- 인터넷 연결 제약
- 프로젝트에 포함될 수 있는 민감자료
- 화면 보기, 타이핑 등 수업 참여에 필요한 지원
