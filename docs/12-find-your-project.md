# 쓸모 있는 프로젝트 찾기 — 나만의 "이런 거 있으면 좋겠다"

> **무엇을** 논문·연구가 아니어도, 내가 평소에 "이런 거 있으면 좋겠다" 싶던 것을 4주 프로젝트로 고르는 방법입니다.
> **왜** 남의 예시보다 내가 실제로 쓰고 싶은 것을 만들 때 끝까지 갑니다.
> **나에게 무슨 의미** 매끈한 소프트웨어가 아니라, 나에게 진짜 쓸모 있는 결과물을 고르게 됩니다.

## 핵심 원칙 — 완성도보다 쓸모

이 과정에서 만드는 결과물은 상품처럼 매끈할 필요가 **없습니다.** 소프트웨어로서 완성도가 낮아도, **나나 다른 한 사람에게 실제로 쓸모가 있으면 그것으로 성공**입니다. 이것이 이 과정이 가장 강조하는 지점입니다.

- 거친 웹페이지라도 매번 찾아 헤매던 정보를 한곳에 모아 주면 성공입니다.
- 투박한 시각화라도 안 보이던 패턴을 보여 주면 성공입니다.
- 버튼 하나짜리 도구라도 반복하던 일을 줄여 주면 성공입니다.

AI에게 많은 부분을 맡겨 빠르게 만들되(요즘 이런 방식을 **바이브 코딩(vibe coding)**, 넓게는 **에이전틱 엔지니어링**이라고 부릅니다), 사람은 "이게 실제로 쓸모 있나"를 판단하고 검증합니다. **기준은 매끄러움이 아니라 쓸모입니다.**

## 어떤 걸 만들면 좋나

"AI 서비스"처럼 크게 생각하지 않습니다. 아래 다섯 갈래 중 **내가 보고 싶은 것**을 고릅니다.

| 갈래 | 이런 것 | 4주 축소판 예시 |
|---|---|---|
| **가시화·시각화** | 흩어진 정보를 한눈에 | 관심 주제의 숫자·추세를 표·그래프 한 장으로 / 내 작업 구조를 [그림 한 장](14-make-a-diagram.md)으로 |
| **튜토리얼·정리** | 나·남이 따라 할 안내 | 내가 겪고 해결한 과정을 단계별 설명 페이지로 |
| **웹페이지** | 모아 두고 다시 보는 곳 | 자주 쓰는 링크·메모·체크리스트를 한 페이지로 |
| **웹앱·도구** | 입력하면 결과가 나오는 것 | 값 하나 넣으면 결과 하나 주는 작은 계산기·변환기 |
| **분석** | 데이터에서 패턴 찾기 | 공개 데이터를 모아 "무엇이 잘 되나" 비교 노트 |

막막하면 **가시화**부터 해 보는 것도 좋습니다. 내 작업 방식이나 프로젝트 구조를 그림 한 장으로 만드는 것은 소재를 새로 찾지 않아도 되고, 결과가 눈에 바로 보입니다. 방법은 [그림으로 설명하기](14-make-a-diagram.md)에 있습니다.

## 나만의 사례 발굴하기

무엇을 만들지 막막하면, 아래 질문에 답을 적어 봅니다. **정답을 찾지 말고 많이 적습니다.**

1. 평소에 "이런 거 하나 있으면 좋겠다" 싶었던 것은?
2. 매번 똑같이 반복하는 귀찮은 일은?
3. 정보가 여기저기 흩어져서 매번 다시 찾는 것은?
4. 남에게 보여 주거나 설명하고 싶은데 정리가 안 된 것은?
5. 궁금한데 아직 한눈에 본 적 없는 숫자·패턴은?

### AI와 함께 발굴하기

혼자 떠오르지 않으면, [2주차의 인터뷰형 프롬프트](03-session-2.md)를 그대로 씁니다.

```text
제가 4주 안에 만들 작고 쓸모 있는 프로젝트를 함께 찾고 싶어요.
바로 제안하지 말고, 제 일상·관심사·반복 작업에 대해 한 번에 하나씩 질문해 주세요.
제 답을 듣고 다음 질문을 정하세요. 충분히 파악되면 그때 후보 3개를 쓸모와 함께 제안해 주세요.
```

## 예시 1 — 유튜브 기획

| 항목 | 내용 |
|---|---|
| "있으면 좋겠다" | 다음에 뭘 찍을지 매번 백지에서 고민한다 |
| 결과물 | 채널 주제 하나에 대한 "다음 영상 10개 아이디어 + 제목·썸네일 문구 후보 + 참고 영상 링크"를 모은 한 페이지 |
| 위임 | "이 주제로 사람들이 궁금해할 각도 10개와, 각각의 제목 후보 2개를 표로 제안해 줘" |
| 검증 | 실제로 찍을 만한 아이디어가 3개 이상 나오는가? 참고 링크가 진짜 존재하는가? |
| 쓸모 | 다음 촬영 때 이 페이지만 열면 바로 시작할 수 있으면 성공 |

### 예시 2 — 유튜브 분석

| 항목 | 내용 |
|---|---|
| "있으면 좋겠다" | 어떤 주제·길이·업로드 패턴이 반응이 좋은지 감이 안 온다 |
| 결과물 | 관심 채널 몇 개의 영상 제목·조회수·길이·업로드 주기를 모은 표 + 간단한 비교 시각화 |
| 위임 | "이 목록에서 조회수 상위 영상들의 공통점을 표로 정리해 줘. 없는 수치는 지어내지 마" |
| 검증 | 표의 숫자가 실제 영상과 일치하는가? (공개된 실제 데이터로 확인) |
| 쓸모 | 다음 기획에서 "이런 각도가 잘 먹힌다"는 근거로 쓸 수 있으면 성공 |

유튜브 데이터처럼 **공개된 정보**는 자유롭게 씁니다. 다만 남의 비공개 자료·개인정보는 넣지 않습니다([정보 분류](01-preflight.md) 참고).

## 쓸모 확인 (이것이 검증입니다)

- [ ] 나 말고 **한 사람**이라도 이걸 실제로 써 보고 싶어 하는가?
- [ ] 거칠어도 지금 **열거나 실행**할 수 있는가?
- [ ] 이게 없을 때보다 **무엇이 편해졌는지** 한 문장으로 말할 수 있는가?

세 가지에 답할 수 있으면, 완성도가 낮아도 성공한 프로젝트입니다.
