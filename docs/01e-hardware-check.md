# 내 장비로 되는지 확인하기

> **무엇을** 지금 가진 노트북으로 이 과정을 할 수 있는지 확인합니다.
> **왜** 대부분은 새로 살 필요가 없습니다. 확인만 하면 됩니다.
> **나에게 무슨 의미** 장비 걱정으로 시작을 늦추지 않게 됩니다.

이 문서는 **구매 안내가 아닙니다.** 특정 기종을 추천하지 않습니다. 구매를 고민할 정도로 막히는 경우는 드물고, 그런 경우에도 아래 기준으로 판단하면 충분합니다.

## 먼저 — 고성능 컴퓨터는 필요하지 않습니다

가장 흔한 오해부터 정리합니다.

> "AI를 쓰려면 GPU 좋은 컴퓨터가 필요하죠?"

**아닙니다.** 이 과정에서 사용하는 AI는 **전부 인터넷 너머의 서버에서 계산됩니다.** 내 컴퓨터는 요청을 보내고 결과를 받아 파일에 저장하는 일만 합니다. 그래서 다음이 성능과 거의 무관합니다.

- CPU 성능
- 그래픽카드(GPU) 유무와 성능
- 최신 기종 여부

AI 모델을 내 컴퓨터에서 직접 돌리는 방식(로컬 LLM)은 이 4주 과정에서 다루지 않습니다. 그런 작업에는 고성능 장비가 필요하지만, 이 과정에는 해당하지 않습니다.

## 실제로 중요한 것 (순서대로)

| 순위 | 확인할 것 | 기준 | 왜 중요한가 |
|---|---|---|---|
| 1 | **프로그램 설치 권한** | 내가 직접 설치할 수 있는가 | 이게 없으면 아무것도 안 됩니다 |
| 2 | **화면 크기** | 창 두 개를 나란히 볼 수 있는가 | 경로 확인, 변경 내용(diff) 보기에 계속 필요 |
| 3 | **저장공간** | 10GB 이상 여유 | 도구 설치와 작업 파일 |
| 4 | **운영체제 버전** | 현재 지원되는 버전인가 | 너무 오래된 OS는 도구 설치가 막힘 |
| 5 | **메모리(RAM)** | 8GB로 가능, 16GB면 편함 | 브라우저·편집기·에이전트를 함께 켜 둠 |
| 6 | 배터리·키보드 | 2시간 수업을 버티는가 | 수업 중 전원 확보 |

**1번이 가장 중요합니다.** 성능 좋은 새 노트북보다, 내가 설치할 수 있는 오래된 노트북이 낫습니다.

### 1번을 확인하는 방법

학교·회사에서 관리하는 컴퓨터는 설치가 막혀 있을 수 있습니다. 아래를 시도해 봅니다.

- 아무 무료 프로그램 하나를 설치해 본다.
- "관리자 권한이 필요합니다" 또는 "조직 정책에 의해 차단됨"이 나오면 **첫 수업 전에 강사에게 알립니다.**

이 경우 개인 장비를 쓰거나, 관리자에게 허용을 요청하거나, 웹 기반 경로로 우회하는 방법을 함께 찾습니다.

## 이런 경우는 어떻게 하나

### 태블릿(아이패드 등)만 있습니다

**이 과정을 진행하기 어렵습니다.** 파일과 폴더를 직접 다루고, Git으로 변경을 기록하고, 에이전트 도구를 실행하는 작업이 태블릿에서는 제한됩니다. 노트북을 빌리거나 공용 PC 사용을 강사와 상의합니다.

### 크롬북이 있습니다

**관리형(학교·회사 배포) 크롬북은 설치 제약이 큽니다.** 개인 크롬북이라도 사용 가능한 도구가 제한될 수 있으니 첫 수업 전에 확인이 필요합니다.

### 5년 이상 된 노트북입니다

**대개 됩니다.** 운영체제가 지원 버전이고 저장공간과 설치 권한이 있으면 충분합니다. 먼저 해 보고, 실제로 막히는 지점이 생기면 그때 판단합니다. 미리 사지 않습니다.

### 가족 공용 컴퓨터를 씁니다

가능합니다. 다만 두 가지를 정해 둡니다.

- 내 작업 폴더를 따로 만듭니다.
- 내 AI 계정으로 로그인하고, 사용 후 로그아웃 여부를 정합니다.

다른 사람의 파일이 있는 폴더를 AI에게 보여 주지 않도록 [정보 분류](01-preflight.md)를 먼저 확인합니다.

## 그래도 새로 구입해야 한다면

장비가 없거나 1번(설치 권한)을 해결할 수 없을 때만 고민합니다. 그때도 기준은 단순합니다.

- **성능보다 화면과 권한.** 화면이 너무 작지 않고, 내가 설치할 수 있으면 됩니다.
- **보급형·중고도 충분합니다.** 위 표의 3~5번을 만족하면 됩니다.
- **AI 전용 사양은 필요 없습니다.** 이 과정의 AI는 클라우드에서 돌아갑니다.
- 이미 쓰는 운영체제를 유지하는 편이 배울 것이 적습니다.

구체적인 기종은 시기마다 바뀌므로 이 문서에 담지 않습니다. 필요하면 강사에게 현재 기준을 문의합니다.

## 휴대폰과 원격 작업

### 휴대폰의 역할

휴대폰은 **확인하고, 시작하고, 짧게 지시하는** 데 씁니다. 제작은 컴퓨터에서 합니다.

| 휴대폰으로 잘 되는 것 | 컴퓨터에서 해야 하는 것 |
|---|---|
| 내 노트·결과물 읽기 | 파일 만들고 정리하기 |
| GitHub에서 결과물 확인 | 변경 내용(diff) 확인하고 커밋 |
| 짧은 질문, 아이디어 메모 | 여러 파일을 함께 다루는 작업 |
| 작업 시작 지시 | 결과 검토와 수정 |

노트를 휴대폰에서 보는 방법은 [Obsidian 볼트 만들기와 모바일 연동](01d-setup-obsidian.md)에 있습니다. 각 도구의 모바일 경로는 [도구 선택 안내](01a-tool-choice.md)를 참고합니다.

### 원격으로 작업하고 싶다면

집 밖에서 내 프로젝트를 이어서 작업하고 싶을 때, **추가 하드웨어는 필요하지 않습니다.** 두 가지 방법이 있습니다.

1. **도구의 클라우드·웹 경로 사용** — GitHub 저장소를 연결해 웹이나 모바일에서 작업합니다. 내 컴퓨터가 꺼져 있어도 됩니다.
2. **내 컴퓨터를 켜 두고 휴대폰에서 조작** — 도구가 지원하는 원격 연결을 사용합니다. 컴퓨터가 켜져 있고 인터넷에 연결되어 있어야 합니다.

### 직접 서버를 만들지 않습니다

"항상 켜져 있는 나만의 서버"를 구성하는 것은 이 과정에서 하지 않습니다. 전원·네트워크·보안·업데이트를 계속 관리해야 하고, 잘못 설정하면 외부에 노출되는 위험이 있습니다. 필요한 원격 작업은 위의 두 방법으로 충분합니다.

### 원격에서 실제로 신경 쓸 것 — 하드웨어가 아니라 권한

휴대폰에서 내 컴퓨터의 작업을 지시할 수 있게 허용하면, **무엇까지 허용되는지**를 알아야 합니다.

- 어떤 폴더를 볼 수 있는가
- 파일을 수정할 수 있는가, 승인이 필요한가
- 명령을 실행할 수 있는가
- 연결을 끊는 방법은 무엇인가

원격 연결을 설정할 때 이 네 가지를 확인합니다. 자세한 기준은 [보안과 공개 기준](07-security-and-sharing.md)에 있습니다.

## 확인 체크리스트

- [ ] 프로그램을 직접 설치할 수 있다. (막히면 강사에게 알림)
- [ ] 저장공간이 10GB 이상 남아 있다.
- [ ] 운영체제가 현재 지원되는 버전이다.
- [ ] 창 두 개를 나란히 놓고 작업할 수 있다.
- [ ] 2시간 수업 동안 전원을 확보할 수 있다.
- [ ] 휴대폰에서 내 노트를 읽을 방법을 정했다. (선택)

여섯 항목 중 첫 세 개가 되면 시작할 수 있습니다. 나머지는 하면서 맞춰 갑니다.
