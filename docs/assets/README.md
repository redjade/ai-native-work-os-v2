## 색의 의미

여섯 그림에서 색을 같은 뜻으로 씁니다.

- 파란색: 지금 작동하거나 보이는 것
- 회색: 사라지거나 보이지 않는 것
- 노란색: 사람이 판단하는 자리

## 수정할 때

- 텍스트 편집기나 AI 도구로 직접 고칩니다. 그림 편집 프로그램이 필요하지 않습니다.
- 배경은 흰색으로 고정했습니다. GitHub의 밝은 화면과 어두운 화면 어디서나 글자가 읽히게 하려는 선택입니다.
- 글꼴은 특정 제품을 지정하지 않고 시스템 글꼴을 사용합니다. 다른 사람 화면에서 깨지지 않게 하려는 것입니다.
- 라벨을 길게 늘이면 상자를 넘칩니다. 한글은 14px에서 한 글자당 약 15px, 12px에서 약 13px로 계산해 상자 너비 안에 들어오는지 확인합니다.
- 새 그림을 추가하면 이 표에 한 줄 넣습니다.

## 왜 그림을 여섯 개로 제한했나

그림은 산문으로 설명하기 어려운 **구조**나 **흐름**을 보여 줄 때만 넣습니다. 장식용 그림은 관리 부담만 늘고, 문서를 고칠 때 그림이 함께 낡습니다. 여기 있는 여섯 개는 모두 여러 번 다시 참조되는 것들입니다.
