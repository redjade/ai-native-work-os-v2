# 수료 후 30일 운영

## 목적

4주 과정의 결과를 일회성 프로젝트로 끝내지 않고 반복 가능한 개인 작업체계로 정착시킵니다.

## 30일 목표 작성

```text
다음 30일에 유지할 프로젝트:
만들 검증 가능한 결과물:
도움을 받을 사용자 또는 검토자:
매주 작업할 시간:
검증 방법:
다음 월간 점검일:
```

## 매주 30분 점검

### 1. 결과물

- 이번 주에 실제로 열거나 실행할 수 있는 것은 무엇인가?
- 완료 조건 중 무엇이 달라졌는가?

### 2. 근거

- 결과가 맞다는 근거는 무엇인가?
- 사람이 다시 확인해야 할 부분은 무엇인가?

### 3. 기록

- 중요한 판단을 기록했는가?
- 반복된 실수를 규칙이나 체크리스트로 바꾸었는가?

### 4. 비용과 시간

- AI가 줄인 시간은 어느 정도인가?
- 검토와 수정에 추가로 든 시간은 어느 정도인가?
- 사용하지 않는 구독이나 도구가 있는가?

### 5. 안전

- 새로 추가된 자료의 정보 등급을 확인했는가?
- 접근 권한과 공개 범위가 여전히 적절한가?

## 30일 동안 권장하는 작업

### 1주차: 반복

같은 산출물 루프를 새로운 작은 작업에 한 번 더 적용합니다.

### 2주차: 정리

사용하지 않는 파일과 도구를 정리하고, 실제로 도움이 된 템플릿만 남깁니다.

### 3주차: 재현

다른 사람에게 README만 전달하고 결과물 확인을 요청합니다.

### 4주차: 개선

진단표를 다시 작성하고 점수가 변한 이유를 근거와 함께 기록합니다.

## 월간 리뷰 산출물

- 이번 달 대표 결과물 1개
- 검증 근거 1개 이상
- 실패 또는 수정 사례 1개
- 새로 만든 규칙·템플릿 1개
- 시간·비용 변화 기록
- 보안 점검 결과
- 다음 달 프로젝트 정의서
