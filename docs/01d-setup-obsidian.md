# Obsidian 볼트 만들기와 모바일 연동

> **무엇을** 노트를 저장할 개인 작업공간(볼트)을 만들고 휴대폰에서도 확인합니다.
> **왜** 이 과정의 지식 노트와 LLM Wiki가 실제로 저장되고 어디서나 열리는 안전한 장소가 필요합니다.
> **나에게 무슨 의미** 챗 세션에서 만든 내용이 사라지지 않고, 컴퓨터와 휴대폰 양쪽에서 같은 노트로 남습니다.

이 문서는 [사전 준비](01-preflight.md)에서 Obsidian을 설치한 뒤에 진행합니다. 설치가 아직이라면 [obsidian.md/download](https://obsidian.md/download)에서 먼저 설치합니다.

## 1. 볼트란 무엇인가

Obsidian에서 **볼트(vault)는 노트가 담기는 폴더 하나**입니다. 특별한 형식이 아니라 컴퓨터의 일반 폴더이며, 그 안의 파일은 모두 `.md`(마크다운) 텍스트 파일입니다.

- 볼트 = 폴더 하나
- 노트 = 그 폴더 안의 텍스트 파일
- 특별한 데이터베이스가 아니므로 Git·GitHub와 그대로 함께 쓸 수 있습니다.

이 점이 중요합니다. Obsidian 볼트를 이 과정의 작업 폴더로 그대로 쓰면, 사람이 읽는 노트(Obsidian)와 변경 기록(Git)이 같은 파일을 공유합니다.

## 2. 데스크톱에서 볼트 만들기

1. Obsidian을 실행합니다.
2. 첫 화면에서 **Create new vault**(새 볼트 만들기)를 선택합니다.
3. 볼트 이름과 위치를 정합니다.
   - 이름 예: `ai-workspace`
   - 위치: 짧은 영문 경로. 예) `~/ai-workspace` (macOS), `C:\Users\<이름>\ai-workspace` (Windows)
4. **Create**를 누르면 빈 볼트가 열립니다.

### 경로 주의

- 경로와 파일 이름에는 **짧은 영문과 하이픈**을 사용합니다. 공백·한글·특수문자는 나중에 Git·CLI에서 문제가 될 수 있습니다.
- 처음에는 **클라우드 동기화 폴더(iCloud Drive, OneDrive, Dropbox, Google Drive) 안에 볼트를 두지 않습니다.** 클라우드 동기화와 Git이 같은 폴더를 동시에 건드리면 충돌이 납니다. 동기화는 아래 4단계의 방법을 사용합니다.

## 3. 최소 폴더 구조 만들기

볼트 안에서 다음 구조를 만듭니다. Obsidian 왼쪽 파일 목록에서 오른쪽 클릭 → 새 폴더/새 노트로 만들 수 있습니다.

```text
ai-workspace/            (볼트 = 폴더)
  HOME.md
  projects/
  knowledge/
    index.md
    sources/
    concepts/
    questions/
  templates/
```

처음부터 복잡하게 나누지 않습니다. 세부 구조는 [1주차](02-session-1.md)에서 프로젝트를 만들며 채웁니다.

## 4. 휴대폰에서 같은 노트 보기

휴대폰에서 노트를 확인하는 방법은 두 가지입니다. **처음에는 A안(무료)** 을 권장합니다.

### A안 — GitHub로 연동 (권장, 무료)

이 과정은 어차피 Git·GitHub로 노트를 백업합니다. 그 저장소를 휴대폰에서 열면 별도 동기화 서비스 없이도 노트를 확인할 수 있습니다.

- **가장 간단한 방법:** 휴대폰 브라우저나 GitHub 모바일 앱에서 본인 저장소를 열어 노트를 **읽습니다.** 마크다운이 화면에 그대로 보입니다.
- **휴대폰에서 편집까지** 하고 싶다면, 데스크톱에서 커밋·푸시한 뒤 휴대폰에서 저장소를 확인하는 흐름으로 시작합니다. 휴대폰의 Obsidian 앱과 Git을 연결하는 것은 초보자에게 설정이 복잡하므로 과정 후반의 선택 과제로 둡니다.

이 방식의 장점: 추가 비용이 없고, "노트가 GitHub에 안전하게 남아 어디서나 보인다"는 이 과정의 핵심 경험과 그대로 이어집니다.

### B안 — Obsidian Sync (공식 유료 동기화)

Obsidian이 제공하는 공식 동기화 서비스입니다. 설정이 가장 단순하고 충돌이 적습니다.

1. 데스크톱 Obsidian → **설정(Settings) → Sync**에서 원격 볼트를 만들고 켭니다.
2. **Android**: Google Play에서 *Obsidian* 앱 설치 → 로그인 → 같은 원격 볼트를 연결.
3. **iOS/iPadOS**: App Store에서 *Obsidian* 앱 설치 → 로그인 → 같은 원격 볼트를 연결.

Obsidian Sync는 유료 구독입니다. 무료로 시작하려면 A안을 사용합니다.

### 하지 않는 것

- iCloud/OneDrive/Dropbox 폴더 안의 볼트를 Git과 동시에 쓰는 방식은 초보 단계에서 권장하지 않습니다. 충돌 원인을 찾기 어렵습니다.
- 휴대폰과 데스크톱에서 **동시에** 같은 노트를 편집하지 않습니다. 한쪽에서 저장·동기화한 뒤 다른 쪽을 엽니다.

## 5. 작동 확인

- [ ] 데스크톱에서 볼트가 열리고 `HOME.md`를 만들 수 있다.
- [ ] 폴더 구조(`projects/`, `knowledge/`, `templates/`)가 보인다.
- [ ] 노트 하나를 만들고 저장할 수 있다.
- [ ] 휴대폰에서 본인 노트(GitHub 저장소 또는 Obsidian 앱)를 열어 읽을 수 있다.
- [ ] 볼트가 클라우드 동기화 폴더 안에 있지 않다.

## 자주 막히는 지점

| 증상 | 확인 |
|---|---|
| 휴대폰에 노트가 안 보임 | 데스크톱에서 커밋·푸시했는가? / 같은 계정·저장소인가? |
| Git 충돌이 잦음 | 볼트가 iCloud·OneDrive 등 동기화 폴더 안에 있지 않은가? |
| 파일 이름이 깨짐 | 경로·파일명에 한글·공백·특수문자가 없는가? |
| 앱에서 편집이 안 됨 | 무료 A안은 휴대폰에서 읽기 위주. 편집은 데스크톱에서 |
