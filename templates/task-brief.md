## 실행 전 요청

파일을 변경하기 전에 다음을 먼저 제시한다.

1. 이해한 목표
2. 확인한 관련 파일
3. 작업 계획
4. 예상 변경 파일
5. 위험과 불확실성

## 실행 후 요청

1. 변경한 내용
2. 검증한 방법과 결과
3. 남은 오류와 불확실성
4. 사람이 직접 확인할 항목

## 복사해 실행할 프롬프트

위 내용을 채운 뒤, 필요에 맞게 아래 빈칸을 바꾸어 AI 도구에 붙여 넣습니다.

```text
[작업]
`[관련 폴더 또는 파일]`을 읽고 [결과물]을 만들어 주세요.

[범위]
[자료 범위]만 사용하고, [금지 사항]은 하지 말아 주세요.

[완료 기준]
[확인 가능한 조건]을 만족해야 합니다.

[진행 방식]
바로 수정하지 말고, 먼저 이해한 목표·작업 계획·예상 변경 파일·위험을 보여 주세요.
작업 뒤에는 검증 결과와 불확실하거나 사람이 확인할 항목을 보고해 주세요.
```

결과가 기대와 다르면 프롬프트 전체를 새로 쓰지 않습니다. 관찰한 실패 하나를 막는 규칙 한 줄을 추가하고, 같은 검증 방법으로 다시 비교합니다.
