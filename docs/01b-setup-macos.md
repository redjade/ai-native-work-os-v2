# macOS 설치 안내

초기 과정은 macOS를 첫 설치 기준으로 사용했습니다. 이 문서는 계속 보완하며, 설치 화면과 명령은 앱 업데이트에 따라 바뀔 수 있으므로 공식 설치 페이지를 함께 확인합니다.

## 목표 상태

첫 수업 전에 다음 상태를 만듭니다.

- Git이 설치되어 있다.
- GitHub에 로그인할 수 있다.
- Obsidian에서 수업 작업 폴더를 열 수 있다.
- Codex 또는 Claude Code 중 주 도구 하나가 작동한다.
- 주 도구가 테스트 프로젝트의 `README.md`를 읽을 수 있다.
- 파일 변경 전에 계획을 확인할 수 있다.

## 1. macOS 기본 확인

- [ ] macOS 업데이트를 확인했다.
- [ ] 관리자 권한 또는 프로그램 설치 가능 여부를 확인했다.
- [ ] 저장공간이 10GB 이상 남아 있다.
- [ ] 이메일과 GitHub 로그인이 가능하다.
- [ ] Finder에서 확장자와 파일 경로를 확인할 수 있다.

## 2. Git 설치와 확인

터미널 앱을 열고 실행합니다.

```bash
git --version
```

버전이 표시되지 않으면 [Git 공식 설치 안내](https://git-scm.com/download/mac)를 사용합니다. 설치 후 터미널을 다시 열고 같은 명령으로 확인합니다.

## 3. Obsidian 설치

1. [Obsidian 다운로드](https://obsidian.md/download)에서 macOS 앱을 설치합니다.
2. 새 볼트를 만들거나 수업용 폴더를 볼트로 엽니다.
3. 첫 파일로 `HOME.md`를 만듭니다.
4. 수업 초기에는 꼭 필요한 플러그인 외에는 설치하지 않습니다.

## 4A. Codex를 주 도구로 선택한 경우

1. [Codex 시작 안내](https://developers.openai.com/codex/quickstart)를 확인합니다.
2. Codex 앱을 설치하고 수업에 사용할 계정으로 로그인합니다.
3. 테스트 프로젝트 폴더를 앱에 추가합니다.
4. 권한 요청이 나타나면 폴더 범위를 확인한 뒤 승인합니다.
5. 다음 요청을 보내고 파일을 수정하지 않은 상태에서 답을 확인합니다.

```text
이 폴더의 파일 목록과 README.md의 목적을 설명해 주세요.
파일은 수정하지 마세요.
```

- [ ] 올바른 폴더를 읽었다.
- [ ] 파일 수정 없이 설명만 반환했다.
- [ ] 변경사항을 확인하는 화면을 찾았다.

## 4B. Claude Code를 주 도구로 선택한 경우

1. [Claude Code 공식 설치 안내](https://docs.anthropic.com/en/docs/claude-code/getting-started)를 확인합니다.
2. 안내된 최신 설치 방법으로 설치합니다.
3. 새 터미널을 열고 다음을 확인합니다.

```bash
claude --version
```

4. 테스트 프로젝트 폴더로 이동해 Claude Code를 시작합니다.
5. 다음 요청을 보내고 파일을 수정하지 않은 상태에서 답을 확인합니다.

```text
이 폴더의 파일 목록과 README.md의 목적을 설명해 주세요.
파일은 수정하지 마세요.
```

- [ ] 올바른 폴더에서 세션을 시작했다.
- [ ] 파일 수정 전에 권한과 계획을 확인할 수 있다.
- [ ] 문제가 있다면 공식 진단 명령과 설치 문서를 확인했다.

## 5. 테스트 프로젝트 만들기

Finder에서 다음 폴더와 파일을 만듭니다.

```text
ai-workspace/
  test-project/
    README.md
    PROJECT.md
```

`README.md`에는 다음 한 줄을 적습니다.

```text
이 프로젝트는 AI 작업환경이 올바른 폴더를 읽는지 확인하기 위한 테스트입니다.
```

## 6. GitHub 연결

교재를 읽는 저장소와 자신의 프로젝트를 저장할 공간을 구분합니다. **자신의 프로젝트와 기록은 별도의 비공개 저장소에서 시작합니다.** 공개 교재 폴더나 공개 fork에 원자료·개인 기록을 추가하지 않습니다.

- [ ] 본인의 작업 저장소를 만들었거나 수업·기관이 제공한 작업 공간을 안내받았다.
- [ ] 브라우저에서 자신의 작업 저장소를 열 수 있다.
- [ ] 작업 저장소의 공개 상태가 Private인지 확인했다.
- [ ] 교재의 공개와 내 자료의 공개는 별개임을 이해했다.
- [ ] 비밀번호나 API 키를 저장소에 올리지 않는다는 것을 이해했다.

## 7. 설치 완료 확인

- [ ] `git --version`이 작동한다.
- [ ] Obsidian에서 작업 폴더가 열린다.
- [ ] 주 도구가 테스트 프로젝트를 읽는다.
- [ ] 주 도구가 읽은 실제 폴더 경로를 확인했다.
- [ ] 변경 전 계획, 변경 후 diff를 확인하는 위치를 안다.
- [ ] 자신의 프로젝트·기록을 둘 별도 비공개 작업 저장소를 확인했다.
- [ ] 해결되지 않은 오류 화면을 캡처했다.

설치 오류가 생기면 임의의 블로그 명령을 계속 실행하지 않습니다. 수업에서는 강사의 지원 경로를 따르고, 교재의 문제는 민감정보를 제거한 오류 설명·운영체제·수행 단계로 [Issue](https://github.com/redjade/ai-native-work-os-v2/issues)를 남깁니다. 내부 화면이나 실제 원자료는 올리지 않습니다.
